# Legado — arquivos da versão inicial do projeto

Estes arquivos refletem decisões anteriores (delegacia especifica, dois perfis de
usuario, PostgreSQL, regime fixo 24x72) que ja foram substituidas pelas decisoes
atuais do projeto:

- Escopo generalizado (qualquer organizacao com escala de turno)
- Um unico perfil de operador: gestor
- Banco de dados: H2 embarcado (modo PostgreSQL), nao mais PostgreSQL via Podman
- Regime de turno configuravel via tabela tipo_turno, nao mais fixo 24x72

Mantidos aqui apenas como referencia historica do projeto.
